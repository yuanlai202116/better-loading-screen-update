# Better Loading Screen Update

A mod to improve the Minecraft loading screen, imitating the old Forge 1.12.2 style. Supports Fabric.

## Build

### Prerequisites
- JDK 21

### Compile
```bash
# Unix
./gradlew :fabric:build

# Windows
gradlew.bat :fabric:build
```

Output: `fabric/build/libs/`
